# Study5-P2 GPU Smoke 결과

**PASS 15/15.** N576의 A·D·G·H·I 5개를 먼저 완료한 뒤 기존 기능 검증 입력으로 N832·N1088에서 각 5개를 완료했다. 이미지당 모델을 한 번 로드하고 모든 방법에서 Vision·Projector 및 한 번의 Probe 계산을 공유했다. 총 모델 로드 3회, Generation 15회다. Dev100·Holdout79 본 평가와 Test400 확정은 수행하지 않았다.

## 환경 및 입력

- NVIDIA GeForce GTX 1660 SUPER 6,144 MiB, 드라이버 621.24. Python vlm_project 3.11.15, PyTorch 2.13.0+cu126, CUDA 12.6, Transformers 5.15.1.
- SmolVLM-256M-Instruct 로컬 snapshot `7e3e67edbbed1bf9888184d9df282b700a323964`. Vision·Text SDPA, FP16, Batch1 No-Padding, Greedy, 최대 10 생성 토큰. Visual K64. 모델·Processor의 이미지 토큰 ID 49190이 일치했다. 네트워크 다운로드와 패키지 업데이트는 없었다.
- `scripts/smoke_gpu.py`에 기존 기능 이미지 해시 및 순위·회귀·Coverage 검사를 추가했다. N576은 P1 고정 질문을 유지했다. N832와 N1088은 Study4 P2-B의 동일 이미지·질문을 재사용했다. 선택 알고리즘 및 Study4 원본 해시는 그대로였다.

- 3개 입력에서 D/G가 동일한 유한 raw FP32 Query 점수 벡터를 사용했다. 입력별 벡터 SHA-256을 저장했다. G seed는 전역 Top-25, H는 전역 Top-64였고 H의 앞 25개가 G seed와 일치했다. I는 D의 seed 25개와 순서가 일치했고 이후 39개는 남은 후보의 Query 순위와 일치했다.
- D/G는 실제 Seed25 Coverage를 초기값으로 39개를 추가했다. 전 방법의 초기·최종 Coverage를 FP64 합산 Reference와 대조했다. 최대 절대오차는 초기 3.061e-6, 최종 1.338e-5이며, 기존 허용 기준 atol 0.001, rtol 1e−6 이내다.
- 전 방법에서 unique K64와 원래 위치 순서, 비시각 토큰 보존 및 compact position을 확인했다. 모든 Decoder 층의 새 KV에서 Prefill하고 Decode가 한 칸씩 append했다. 생성 logits는 유한했고 NaN/Inf·CUDA 오류·OOM은 없었다.
- Transformers는 로컬 설정의 `pad_token_id=128002`가 표기된 vocabulary 범위 밖이라는 경고를 로드 시 출력했다. 실제 All-valid Batch1 입력은 padding row 0이었고, 모델·Processor 이미지 토큰과 계산 프로파일 검사를 통과했다. 모델·Tokenizer 설정을 수정하지 않았다.

## Study4 A/D 회귀

동일한 실측 입력으로 Study4 원본과 같은 A/D 함수와 다시 비교했다. 3개 구조 모두 seed, 선택 순서, 원본 위치 및 Coverage trace가 정확히 일치했다. N832·N1088의 기존 Study4 기록과도 A/D의 seed, 선택 토큰 ID, 원본 위치 및 생성 토큰 ID가 모두 일치했다. 과거 Coverage 값과의 차이는 N1088 A에서만 1.526×10⁻⁵였고 나머지 3조건은 0이었다. N576 과거 Study4 Smoke는 질문이 달라 역사적 생성 ID parity는 비교하지 않았다. 과거 logits 원시값 비교는 수행하지 않았다.

## P3 준비 상태와 BLOCKER

A/D/G/H/I의 GPU 기능 Gate를 완료했다. Dev100 성능 평가는 기존 고정 Manifest와 동일 조건을 쓰는 평가 Runner 및 재개 계약의 별도 검증을 거쳐야 한다. Holdout79는 노출 이력의 미확인 범위가 남아 독립 평가셋으로 확정되지 않았다. Left-Padding FP16 parity BLOCKER는 별도로 유지한다. P2는 기능 검증까지 수행했다.
